웹 조작방법

  1. 로봇 연결 — 로봇을 선택하고 ‘연결 설정’에서 해당 로봇 PC의 rosbridge 주소를 입력한 뒤 저장하세요.
  2. ALL 보기 — Robot 1과 Robot 2의 연결·기체·TF·카메라를 함께 표시합니다. 기존 주행 연결은 유지되고, 주행 제어는 비활성화됩니다.
  3. 화면 이동 — 우클릭 드래그, 확대·축소는 마우스 휠, 회전은 좌클릭 드래그입니다.
  4. 초기 위치 — ‘초기 위치’를 누르고 지도에서 로봇이 실제로 놓인 위치를 누른 채 바라보는 방향으로 드래그하세요. 주황색 원과 화살표를 확인하고 ‘초기 위치 적용’을 누릅니다. 위치 추정 설정이며 로봇을 그곳으로 이동시키지 않습니다.
  5. 목적지 선택 — 상단 ‘목적지’를 누르고 지도의 빈 공간을 클릭하세요. 원형 표식이 생깁니다. 누른 채 드래그하면 도착 방향도 지정합니다.
  6. 자율주행 — 위치를 확인한 뒤 ‘자율주행’을 누르면 선택한 로봇에 전송됩니다. 지도 클릭만으로 출발하지 않습니다.
  7. 정지 — 단독 보기에서는 선택 로봇에, ALL에서는 Robot 1과 Robot 2 모두에 Nav2 취소와 속도 0을 전송합니다. 하드웨어 비상정지 기능은 아닙니다.
  8. 선택 취소 — Esc 또는 ‘선택 취소’로 목적지를 지웁니다. 진행 중인 주행은 ‘정지’를 사용하세요.
  9. 표시 설정 — Grid·지도·기체·경로·라이다·TF를 켜고 끌 수 있습니다. ‘지도 맞춤’은 지도 전체를 보여줍니다.

오프라인 테스트에서는 목적지 선택과 버튼만 시험하며 로봇에 명령을 보내지 않습니다.

로봇 연결 설정

해당 로봇을 실행하는 PC의 rosbridge 주소를 입력하세요.
